#### 新建项目

###### 1.使用命令创建vue3 &&t s项目

npx degit dcloudio/uni-preset-vue#vite-ts ncx-music

然后

```
pnpm add -D @dcloudio/types
```

再

```
pnpm add -D @vue/tsconfig
```

重启vscode，再无报错

接着安装依赖

```
pnpm install
```

 

###### 2.使用命令安装uniapp-ui

```
pnpm i @dcloudio/uni-ui

```

在// pages.json

```json

// pages.json
{
  // 组件自动导入
  "easycom": {
    "autoscan": true,
    "custom": {
      // uni-ui 规则如下配置  
      "^uni-(.*)": "@dcloudio/uni-ui/lib/uni-$1/uni-$1.vue" 
    }
  },
  "pages": [
    // …省略
  ]
}
    }
```



###### 3.关于类型声明文件

```
pnpm i -D @uni-helper/uni-app-types@latest @uni-helper/uni-ui-types@latest
```

```json
// tsconfig.json
{
  "compilerOptions": {
    // ...
    "types": [
      "@dcloudio/types", // uni-app API 类型
      "miniprogram-api-typings", // 原生微信小程序类型
      "@uni-helper/uni-app-types", // uni-app 组件类型
   //++++   添加下面这句
       "@uni-helper/uni-ui-types" // uni-ui 组件类型  
    ]
  },
  // vue 编译器类型，校验标签类型
  "vueCompilerOptions": {
    // 原配置 experimentalRuntimeMode 已废弃，请升级 Vue - Official 插件至最新版本
    //++++   添加下面这句
    "plugins": ["@uni-helper/uni-app-types/volar-plugin"] 
  }
}
```

###### 4.小程序端持久化pinia

pnpm i pinia-plugin-persistedstate

```ts
  //在store.ts中
  {
    // 配置持久化
    persist: {
      // 调整为兼容多端的API
      storage: {
        setItem(key, value) {
          uni.setStorageSync(key, value) 
        },
        getItem(key) {
          return uni.getStorageSync(key) 
        },
      },
    },
  },
```
